\# Tag 3



\*\*Was gelernt?\*\*

Der tägliche Ablauf (Datei anlegen, add, commit, push) läuft mir mittlerweile

flüssig von der Hand. Ich habe außerdem verstanden, dass jeder Commit in

der Historie sichtbar bleibt — man kann auf GitHub genau nachvollziehen,

wann welche Datei dazukam.



\*\*Welches Problem?\*\*

Mir war nicht ganz klar, wie ich sehen kann, was sich seit dem letzten

Commit überhaupt verändert hat, bevor ich `git add` ausführe.



\*\*Wie gelöst?\*\*

Ich habe gelernt, dass `git status` genau das anzeigt: welche Dateien neu,

geändert oder noch nicht "eingecheckt" sind. Das gibt mir mehr Sicherheit,

bevor ich committe.
