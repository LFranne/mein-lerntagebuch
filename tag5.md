\# Tag 5



\*\*Was gelernt?\*\*

Ich habe heute meinen ersten Pull Request erstellt und gemergt. Ich verstehe

jetzt, dass ein PR der Ort ist, an dem man die Änderungen aus einem Branch

in main übernimmt — auf GitHub kann man dabei genau sehen, was sich ändert,

bevor man zustimmt.



\*\*Welches Problem?\*\*

Der gelbe "Compare \& pull request"-Banner, den ich erwartet hatte, war auf

der Repo-Seite gar nicht mehr zu sehen.



\*\*Wie gelöst?\*\*

Ich habe den PR stattdessen über den Reiter "Pull requests" → "New pull

request" erstellt und dort base (main) und compare (mein Branch) manuell

ausgewählt. Hat genauso gut funktioniert.
